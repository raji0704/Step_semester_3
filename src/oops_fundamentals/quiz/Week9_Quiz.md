# Week 9 Quiz – OOPS Fundamentals

## 1. What does abstraction mainly achieve?

A. Showing all implementation details  
B. Removing all methods  
C. Hiding how operations work and showing what they do  
D. Removing classes

**Answer: C**

---

## 2. Which statement about an abstract class is true?

A. It must always have only abstract methods  
B. It cannot have constructors  
C. It cannot be instantiated directly  
D. It cannot have concrete methods

**Answer: C**

---

## 3. What happens if a concrete subclass does not implement all abstract methods?

A. Program runs normally  
B. The subclass must be abstract or a compile-time error occurs  
C. Abstract methods become private  
D. Constructor is removed

**Answer: B**

---

## 4. Which modifier is NOT allowed with an abstract method?

A. public  
B. protected  
C. private  
D. default

**Answer: C**

---

## 5. By default, fields declared inside an interface are:

A. private  
B. protected  
C. public static final  
D. public abstract

**Answer: C**

---

## 6. How many interfaces can a Java class implement?

A. Only one  
B. Maximum two  
C. Any number  
D. None

**Answer: C**

---

## 7. What access level must an implemented interface method have?

A. private  
B. protected  
C. default  
D. public

**Answer: D**

---

## 8. Why can a Java class implement multiple interfaces?

A. Interfaces support multiple class inheritance  
B. Interfaces cannot contain methods  
C. Interfaces avoid ambiguity in instance-state inheritance  
D. Java allows multiple superclass inheritance

**Answer: C**

---

## 9. Two interfaces contain the same default method. A class implements both but does not override the method. What happens?

A. First interface method is automatically selected  
B. Second interface method is automatically selected  
C. Program runs normally  
D. Compile-time error occurs

**Answer: D**

---

## 10. When is an abstract class constructor executed?

A. Never  
B. When an object of a subclass is created  
C. Only when the abstract class is directly instantiated  
D. Only when an abstract method is called

**Answer: B**
